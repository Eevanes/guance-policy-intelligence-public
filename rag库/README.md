# RAG 工程

此目录发布当前切块、存储与检索实现，不提供政策正文、图片、训练集、索引、向量缓存或运行数据库。

- `切块工程`：输入处理、分段及 tokenizer 配置。
- `向量化与存储工程（降级版）`：本地存储、嵌入和运行包恢复代码。
- `检索工程`：只读检索、原文坐标、媒体读取与 Agent 接口。

配置中的 `sample_planids` 在公开版为空，需根据自己的授权数据设置。嵌入模型服务及 tokenizer 按自己的配置准备；示例配置不包含凭据。真实运行需要自行建库，公开版没有预建运行包。

检索工程可从仓库根目录安装 `python -m pip install -e './rag库/检索工程'`。契约类型离线测试为 `python -m pytest 'rag库/检索工程/ci_tests' -q`；依赖至少包括 Pydantic 2 和 pytest，测试使用合成输入，不读取比赛语料。
