# 公开版范围

本仓库只发布经过隔离的工程代码与合成 Demo，完整开发副本继续保存在私人仓库。

## 纳入内容

Agent 运行与业务模块、React 前端、FastAPI 后端、当前切块/存储/检索代码，以及无需真实语料即可执行的离线测试。前端研究入口、阅读器、引用布局与个人版本一致。

前端原有 506 篇文献的主题映射已替换为 `DEMO-A`、`DEMO-B`、`DEMO-C` 三份合成示例；分类关联仅用于交互演示，不是对真实政策的分类结果。Agent mock 知识库使用 `TEST-*` 标识的合成资料。

## 未纳入内容

- 比赛原始数据库、训练题、原始对话、清理语料及政策 Word/PDF/HTML/图片原件。
- 冻结正文、OCR 结果、向量、索引、数据库、缓存和 RAG Release 附件。
- 真实 RAG 返回的契约样例、实际模型/检索验收记录、真实业务输出样例。
- 来源仓库的分支、标签和提交历史，以及未经逐项审查的项目材料。
- 与真实样例文件绑定的契约测试、真实运行测试，以及检测到长原文重叠的阅读器回归样例。
- 与受限训练集存在连续文本重叠的部分问答、路由、研究准备及富文本回归用例。

原数据说明存在仅限比赛使用、不得外传及不出校园网的要求，因此公开版不提供数据下载。需要真实研究时，应自行取得数据和模型服务的使用授权。恢复工具代码保留，不表示原有运行包已在此仓库提供。

## 运行与验证边界

Demo 可以独立体验。真实 RAG 的安装、建库、向量空间一致性和回答质量需在自己的授权数据环境中验证。离线测试与构建通过，不能替代这些验收。

公开版保留源码归属，但没有新增统一开源许可证。公开可读与获得修改、再分发授权是不同事项。
